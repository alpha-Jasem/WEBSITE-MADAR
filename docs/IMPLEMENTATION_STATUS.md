1. ربط n8n (المالك يعطي الرابط والمفتاح).
2. مراجعة بصرية للوحة والجوال بجلسة المالك، وتفعيل الإشعارات على الجوال.
3. قرار المهام الفاشلة `cw-*`.
4. استكمال المرحلة 0: لقطة المخطط، نسخ احتياطي مجدول واختبار استعادة، سحب `admin-create-client`/`clinic-usage` إن كانتا منشورتين.
5. المرحلة 1: واجهة إعداد الحملات (`campaigns`)، وكتابة أحداث الصفقات من كل مسارات Outreach، وتوحيد توكنز التصميم مع لوحة العميل.
