# سجل جلسة Claude — موقع ومنصة مدار

> هذا **ملخص منظّم** للجلسة وليس نصاً حرفياً لكل الرسائل. الجزء الأول من المحادثة اختُصر تلقائياً أثناء العمل، فلا تتوفر نسخة كلمة بكلمة منه. للنص الكامل: افتح المحادثة في Claude وشاركها من زر Share.

## الهدف
بناء موقع مدار التسويقي ومنصة العملاء (داشبورد إدارة واتساب والوكلاء الذكيين) كصفحة واحدة، بهوية «المدار / الفضاء»، ثم مطابقة ميزات منصة كرزون شات بكود وتصميم خاصين بمدار.

## ما طُلب وما نُفّذ (بالترتيب)

### الموقع التسويقي
- **ثيم المدار:** نجوم، مدار حول الهيرو بأقمار صناعية، أقواس مدارية على الأقسام.
- **قسم الصوت (`#voice`):** مشغّل بموجة صوتية وسرعة تشغيل ورجوع.
- **جولة المنصة الحية (`#tour`):** المنصة الحقيقية مضمّنة في iframe، وأزرار في الصفحة تتحكم بها (البريد، الرئيسية، الوكلاء، الحملات، الأتمتة، القنوات، الطلبات، التقارير) — بدل داشبورد مزيّف.
- **الشركاء والتطبيقات (`#apps`):** سلة، زد، Google Play، App Store، ميتا + صف تطبيقات في الفوتر. أُزيل Galaxy Store بطلب فيصل. الروابط والتواريخ فاضية حتى تصل البيانات الحقيقية (بدون تواريخ مختلقة).
- **اختر عقلك:** 4 نماذج فقط بشعاراتها: ChatGPT، Claude، Gemini، DeepSeek.
- واجهة عربية/إنجليزية.

### منصة العملاء
- **عروض الأسعار:** إيميل العميل + رسالة افتراضية قابلة للتعديل + زر إرسال (الإرسال حالياً محاكاة؛ الإرسال الفعلي يحتاج SMTP/خادم).
- **لوحة المطورين الداخلية** (فيصل وجاسم) — بيانات دخول تجريبية فقط.
- **الجولة الأولى لكرزون (pf7):** الحضور والانصراف، النوافذ الذكية، المشغّلات، مجموعات الصلاحيات، مصفوفة الإشعارات، الأمان (2FA + مفاتيح المرور)، مراحل العملاء، المنتجات والخدمات، تطبيقات المحادثة.
- **الجولة الثانية المفصّلة (pf8)** بعد قراءة كل شاشات كرزون — انظر `KARZOUN_FEATURE_INVENTORY.md`.

## قرارات مهمة
- **لا نسخ لكود كرزون:** طلب فيصل «نفس الأكواد». وضّحت إن نسخ كود كرزون المصدري ممنوع (ملكية فكرية) فطابقنا الميزات والحقول والتدفقات بكود مدار الخاص. القراءة كانت بقراءة فقط من حساب ONEHARDSET وما انتقلت أي بيانات عملاء للريبو.
- **الصدق في الواجهة:** شريط «نسخة تجريبية»، والأرقام توضيحية، وبدون شراكات أو تواريخ مختلقة.
- **مشاركة الجلسة:** المحادثات المشاركة في Claude للعرض فقط، فالحل مشاركة الـ Artifact + هذا الريبو.

## المتبقي
1. ربط الواجهة بـ Supabase + n8n + Meta WhatsApp API (حالياً الحالة كلها في الذاكرة).
2. إدخال روابط المتاجر وتواريخ الشراكة الحقيقية (`site2.js`).
3. الفجوات المتبقية مقابل كرزون: رحلة العميل، مساعد الفريق «زكي»، بكسل نشاط الموقع، الشركات واختيار الأعمدة في جهات الاتصال، المتجر.
4. الإرسال الفعلي للبريد (عروض الأسعار والقوالب) عبر خادم.
