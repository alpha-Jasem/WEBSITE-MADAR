# موقع ومنصة مدار — نسخة جلسة Claude

هذا المجلد يحتوي كل الشغل اللي انبنى في جلسة Claude: موقع مدار التسويقي، ومنصة العملاء (داشبورد) مضمّنة فيه، والملف التعريفي للشركة.
وضعته في مجلد مستقل حتى **ما يلمس** مشروع React/Vite الموجود في جذر الريبو.

- **العرض المباشر (Artifact):** https://claude.ai/artifact/N6on8SW8QukPxtroNfKHqe
- **الملف الجاهز:** `output/madar-site.html` — صفحة واحدة مستقلة، افتحها في أي متصفح.

## الهيكل

| المسار | المحتوى |
|---|---|
| `src/site.body.html`, `site.css`, `site2.js` | الموقع التسويقي (الهيرو المداري، الصوت، جولة المنصة الحية، الشركاء، اختيار العقل، الأسعار…) |
| `src/pf1.js` … `pf8.js`, `pf.css` | منصة العملاء (تطبيق صفحة واحدة بدون مكتبات) |
| `src/build_site.py` | يجمع كل شيء في `output/madar-site.html` |
| `src/brands.py`, `brands.json` | شعارات القنوات والمتاجر (SVG sprite) |
| `src/pricing.json` | الأسعار وأسعار ميتا التقديرية |
| `src/voice.mp3`, `peaks.json` | المقطع الصوتي وموجته |
| `src/profile.*`, `print.tpl.html` | الملف التعريفي للشركة (PDF/HTML) |
| `assets/` | الصور المضمّنة |
| `tests/` | سكربتات Playwright اللي استخدمتها للتحقق |
| `KARZOUN_FEATURE_INVENTORY.md` | جرد ميزات منصة كرزون (المعروضة للعميل) ومقارنتها بمدار |
| `SESSION_LOG.md` | سجل الجلسة: الطلبات، القرارات، والمتبقي |

## البناء

```bash
cd src && python3 build_site.py   # يكتب ../output/madar-site.html
```

## تنبيهات مهمة

- **كل شيء واجهة أمامية تجريبية.** البيانات في الذاكرة، والإرسال (بريد/واتساب/ويب هوك) محاكاة. التشغيل الفعلي يحتاج backend (Supabase + n8n كما في `MADAR_MASTER.md`).
- بيانات دخول المطوّر في `pf6.js` تجريبية للعرض فقط — **لا تستخدمها كحماية حقيقية**؛ أي تحقق فعلي لازم يصير على الخادم.
- روابط المتاجر وتواريخ الشراكة (`STORE_LINKS`, `SINCE` في `site2.js`) فاضية بانتظار البيانات الحقيقية.
- الشعارات التجارية (سلة، زد، Google Play، App Store، نماذج الذكاء) مستخدمة للإشارة فقط.
